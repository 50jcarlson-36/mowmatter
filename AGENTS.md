# MowMatter agent instructions

Before project setup, connection troubleshooting, deployment or production status work, read [docs/PROJECT-OPERATIONS-CONTRACT.md](docs/PROJECT-OPERATIONS-CONTRACT.md).

It records the approved architecture, account/service identifiers, deployment paths, commercial decisions, evidence and unresolved blockers. Consult it before asking the owner to repeat information. Reverify time-sensitive state through the available connectors and update the contract when facts change.

Never store credentials in these files. Keep MowMatter work separate from other projects in shared accounts. A successful build is not proof that mowmatter.com serves that deployment; verify the public domain and asset versions. Use expected-SHA updates and preserve unrelated changes.
